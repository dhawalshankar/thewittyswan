# netsec books

A curated collection of books covering computer networking, network security, protocol analysis, penetration testing, cryptography, and network defence.

## Fundamentals of Networking

1. **Computer Networking: A Top-Down Approach** — James Kurose & Keith Ross
   - Excellent foundation in networking, protocols, TCP/IP, DNS, HTTP and network architecture.
   - Level: Beginner–Intermediate

2. **TCP/IP Illustrated, Volume 1: The Protocols** — W. Richard Stevens & Kevin Fall
   - An in-depth exploration of TCP/IP protocols and their real-world behaviour.
   - Level: Intermediate–Advanced

3. **Computer Networks** — Andrew S. Tanenbaum & David J. Wetherall
   - Comprehensive coverage of network architecture, routing, protocols and network design.
   - Level: Beginner–Intermediate

## Network Security & Defence

4. **Network Security Essentials: Applications and Standards** — William Stallings
   - Covers network security architecture, authentication, encryption, IP security and secure communication.
   - Level: Beginner–Intermediate

5. **Network Security Assessment** — Chris McNab
   - Practical techniques for assessing network infrastructure, identifying vulnerabilities and evaluating security controls.
   - Level: Intermediate–Advanced

6. **The Practice of Network Security Monitoring** — Richard Bejtlich
   - Learn network monitoring, traffic analysis, intrusion detection and incident investigation.
   - Level: Intermediate–Advanced

## Packet Analysis & Network Forensics

7. **Practical Packet Analysis (3rd Edition)** — Chris Sanders
   - A hands-on guide to understanding network traffic using Wireshark and packet captures.
   - Level: Beginner–Intermediate

8. **Wireshark 101** — Laura Chappell
   - Practical exercises for capturing, filtering and analysing network traffic.
   - Level: Beginner–Intermediate

## Offensive Network Security

9. **Attacking Network Protocols** — James Forshaw
   - Explore protocol analysis, reverse engineering and techniques for discovering protocol vulnerabilities.
   - Level: Advanced

10. **Nmap Network Scanning** — Gordon Lyon
    - A comprehensive guide to network discovery, port scanning, service enumeration and security auditing.
    - Level: Beginner–Advanced

11. **Silence on the Wire** — Michal Zalewski
    - An exploration of network security, information leakage, traffic analysis and the subtle behaviour of network protocols.
    - Level: Intermediate–Advanced

## Cryptography & Secure Communication

12. **Cryptography and Network Security** — William Stallings
    - A detailed introduction to cryptographic algorithms, authentication, digital signatures and secure network protocols.
    - Level: Beginner–Intermediate

13. **Serious Cryptography** — Jean-Philippe Aumasson
    - Understand modern cryptographic primitives, their implementation and common security pitfalls.
    - Level: Intermediate–Advanced

14. **Real-World Cryptography** — David Wong
    - A practical introduction to modern cryptographic systems and their applications in software and network security.
    - Level: Intermediate

---

## Suggested Reading Order

For readers starting their journey into network security:

1. Computer Networking: A Top-Down Approach
2. Network Security Essentials
3. Practical Packet Analysis
4. TCP/IP Illustrated
5. Nmap Network Scanning
6. The Practice of Network Security Monitoring
7. Attacking Network Protocols
8. Serious Cryptography

**Recommendation:** Do not limit yourself to reading. Practise alongside these books using Wireshark, Nmap, Linux, virtual machines and authorised network security labs.

*Knowledge of how networks work is the foundation of understanding how to secure them.*
